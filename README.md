# Практическая работа №05: PHP ООП. Классы, конструкторы и модели предметной области

## Описание проекта
Учебное веб-приложение каталога товаров, реализующее переход от процедурного кода к объектно-ориентированной модели. Приложение загружает данные из JSON-файлов, инкапсулирует сущности в строгие модели с валидацией входных параметров и выводит каталог с возможностью фильтрации по категориям и подсчетом аналитических метрик.

## Схема взаимодействия компонентов
                          [ data/*.json ]
                                │
                                ▼
[ CatalogService ] ──(создает и валидирует)──> [ Product & Category Models ]
                                │
                                ▼ (передает готовые коллекции объектов)
                        [ public/index.php ]
                                │
                                ▼ (рендерит HTML)
                [ Пользовательский интерфейс / Браузер ]
